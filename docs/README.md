# OctoAcme Project Management Process Docs — README

This README provides a brief summary of OctoAcme's project management processes and direct links to the full process documents in this repository's docs/ folder.

## Summary of OctoAcme Project Management Processes

OctoAcme operates on a customer-first, iterative delivery model with clearly defined ownership and data-driven decision-making. The organization structures projects around five key lifecycle phases: **Initiation**, **Planning**, **Execution**, **Release**, and **Close & Retrospective**. 

Projects begin with a lightweight initiation phase that validates business need through a Project One-pager, establishes stakeholder alignment, and creates a high-level timeline. Once approved, the intensive planning phase breaks work into shippable increments, defines acceptance criteria, and identifies dependencies and risks upfront. At the heart of this framework are three core roles—Project Manager (PM), Product Manager (PdM), and Development teams—each with distinct responsibilities.

During execution, OctoAcme teams operate within a structured cadence: daily standups (15 min) focus on progress and blockers, weekly delivery syncs track metrics and flag risks, and sprint-based iterations deliver through a GitHub Projects workflow. Pull requests are kept lean (≤400 lines when possible) and must include issue links and acceptance criteria. Quality assurance is embedded throughout—teams run unit tests, integration tests, end-to-end smoke tests, and security scans in CI before requesting review.

Risk management and stakeholder communication are maintained throughout via a simple Risk Register and regular status templates. Releases are standardized across Patch, Minor, and Major categories with rigorous pre-release requirements. After each sprint, release, or milestone, teams hold retrospectives to capture learnings and identify 2–3 top improvement actions with clear owners and due dates, completing a feedback loop that reinforces psychological safety and iterative refinement.
